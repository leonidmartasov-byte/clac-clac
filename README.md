### Що реалізовано в коді:
* **Програмний спрайтшіт (`generateSpriteSheet`):** генерує таблицю `3 × 4` кадри (3 рядки станів по 4 кадри в кожному), яка одразу відображається в панелі справа для наочності.
* **Перемикання швидкості та станів:**
  * Клавіша **`1`** — `idle` (стояти, повільне дихання **3 FPS**).
  * Клавіша **`2`** — `walk` (крокувати, **11 FPS**).
  * Клавіша **`3`** — `run` (бігти з нахилом вперед, **15 FPS**).
* **Адаптивний Hitbox:** для стану `idle` він вузький (`24×52`), для `walk` трохи ширший (`32×52`), а для `run` — широкий та нижчий (`42×46`) через нахил тіла вперед. Прямокутник автоматично масштабується разом зі слайдером і дзеркально зміщується при натисканні **Flip**.
